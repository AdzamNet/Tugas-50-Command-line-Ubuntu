# Tugas-50-Command-line-Ubuntu
50 command line di ubuntu


1.  ls                   - lihat isi folder
2.  pwd                  - tampilkan direktori sekarang
3.  cd ..                - naik satu folder
4.  cd                   - pindah ke home folder
5.  mkdir                - buat folder baru
6.  ls -la               - lihat isi folder + file tersembunyi + detail
7.  rmdir                - hapus folder kosong
8.  rm                   - hapus file
9.  rm -r                - hapus folder + isinya
10. cp                   - salin file
11. mv                   - pindah/rename file
12. touch                - buat file kosong
13. find                 - cari file di sistem
14. locate               - cari file cepat
15. tree                 - tampilkan struktur folder
16. less                 - lihat file per halaman
17. head                 - lihat baris awal file
18. cat                  - tampilkan isi file
19. tail                 - lihat baris akhir file
20. tail -f              - pantau file real-time
21. nano                 - edit file mudah
22. vim                  - edit file advanced
23. apt search           - cari paket
24. uname -a             - info kernel & sistem
25. df -h                - cek penggunaan disk
26. free -h              - cek penggunaan RAM
27. du -sh               - cek ukuran folder
28. sudo apt update      - update daftar paket
29. sudo apt upgrade     - update semua paket
30. sudo apt install     - install paket
31. sudo apt remove      - hapus paket
32. sudo apt autoremove  - bersihkan paket tak terpakai
33. top                  - pantau proses
34. htop                 - pantau proses interaktif
35. whoami               - lihat user aktif
36. hostname             - lihat nama komputer
37. uptime               - lihat lama sistem nyala
38. ps aux               - lihat semua proses
39. kill                 - hentikan proses
40. kill -9              - paksa hentikan proses
41. ifconfig             - lihat konfigurasi jaringan lama
42. ip a                 - lihat konfigurasi jaringan
43. curl -O              - download file dari url
44. wget                 - download file
45. chmod                - ubah izin akses file
46. chown                - ubah pemilik file
47. tar -xvzf            - ekstrak file arsip
48. sudo service start   - jalankan layanan
49. sudo service stop    - hentikan layanan
50. sudo service status  - cek status layanan
